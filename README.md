# Character_counter
A simple **Character Counter** project built using HTML, CSS, and JavaScript.

## Live Demo

[View Character Counter](https://anishams10.github.io/character_counter/)

## Features

* Counts characters while typing.
* Shows the current character count.
* Changes the textarea border color when the character limit is exceeded.
* Simple and responsive design.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Enter your text in the textarea.
2. The character count updates automatically while typing.
3. If the character limit is exceeded, the textarea border changes to red.
